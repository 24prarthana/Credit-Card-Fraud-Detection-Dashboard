💳 Credit Card Fraud Detection Dashboard
An end-to-end Machine Learning project that detects fraudulent credit card transactions using a Random Forest Classifier and an interactive Streamlit dashboard.

🚀 Features
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Class Imbalance Handling
Random Forest Classification
Fraud Prediction System
Interactive Streamlit Dashboard
Model Performance Visualization

📊 Model Performance
Metric	Score
Accuracy	99.92%
Precision	74.32%
Recall	85.94%
F1 Score	79.71%

🛠️ Technologies Used
Python
Pandas
NumPy
Scikit-Learn
Streamlit
Matplotlib
Joblib

📂 Project Files
Fraud.ipynb – Complete model development and training process
main.py – Streamlit dashboard application
fraud_model.pkl – Trained Random Forest model
scaler.pkl – Saved StandardScaler model

▶️ Run the Project
Install dependencies:

pip install -r requirements.txt
Run the dashboard:

streamlit run main.py
